One-liner entry for the [Roast Your Own Agent](https://make.fun/c/u-febri-yudila-roast-your-own-agent-f3359068) bounty on make.fun.

## Entry

> My agent apologized for the error, then confidently fixed it by making the exact same error in a different file.

## How it works

`main.ts` writes that single line to `entry.txt` inside the output directory
(`$MAKEFUN_OUTPUT_DIR`, or `out/` by default). Nothing else goes in the file.

Run it with Node 22:

```sh
node main.ts
```
